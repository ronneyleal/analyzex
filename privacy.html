🔒 Política de Privacidade – AnalyzeX

Conheça como tratamos seus dados no aplicativo e na plataforma.
Última atualização: 20/12/2025 Uso corporativo Acesso a relatórios Power BI

A AnalyzeX respeita a privacidade dos usuários e está comprometido com a proteção dos dados pessoais tratados por meio do aplicativo. Esta Política de Privacidade descreve como as informações são coletadas, utilizadas, armazenadas e protegidas.

Ao utilizar o aplicativo AnalyzeX, você concorda com as práticas descritas nesta Política.

1. Quem somos

A AnalyzeX é uma plataforma corporativa destinada a empresas, organizações e seus colaboradores, oferecendo recursos de relatórios, indicadores, comunicação interna, gestão operacional, pesquisas e ferramentas de apoio à decisão.

Responsável pelo tratamento dos dados:
AnalyzeX
E-mail de contato: contato@analyzex.com.br

2. Dados coletados

A AnalyzeX coleta apenas os dados necessários para o funcionamento adequado da plataforma.

A AnalyzeX disponibiliza acesso a relatórios e dashboards desenvolvidos em Power BI, integrados a sistemas corporativos e bases de dados próprias de cada empresa.

O aplicativo não coleta dados diretamente da plataforma Power BI de forma independente, atuando apenas como interface de acesso aos relatórios e informações autorizadas pela empresa contratante, respeitando os níveis de permissão definidos para cada usuário.

2.1 Dados fornecidos pelo usuário

  • Nome
  • E-mail
  • Nome de usuário
  • Cargo ou função
  • Data de nascimento (quando exigido pela empresa)
  • Foto de perfil (opcional)
  • Mensagens enviadas no chat
  • Conteúdo publicado em comunicados, posts e comentários
  • Respostas a pesquisas (NPS, enquetes e formulários)
  • Dados enviados em candidaturas (quando aplicável)

2.2 Dados coletados automaticamente

  • Identificador do dispositivo
  • Token de notificação push
  • Endereço IP
  • Informações de acesso (data, hora, última atividade)
  • Tipo de dispositivo e sistema operacional
  • Registros de uso para fins de segurança e auditoria

2.3 Permissões do aplicativo

O aplicativo pode solicitar acesso a:

  • Microfone – para envio de mensagens de áudio no chat
  • Galeria e arquivos – para envio de imagens e documentos
  • Notificações – para alertas, mensagens e comunicados
  • Internet – para funcionamento da plataforma

Nenhuma permissão é utilizada sem ação direta do usuário.

3. Finalidade do uso dos dados

Os dados coletados são utilizados para:

  • Autenticação e controle de acesso
  • Comunicação interna entre usuários
  • Exibição de relatórios e indicadores
  • Gestão de tarefas, reuniões e processos
  • Aplicação e análise de pesquisas de satisfação (NPS)
  • Envio de notificações
  • Cumprimento de obrigações legais
  • Segurança, auditoria e prevenção de fraudes
  • Melhoria contínua da plataforma

4. Compartilhamento de dados

A AnalyzeX não vende dados pessoais.

Os dados podem ser compartilhados apenas:

  • Com a empresa à qual o usuário pertence
  • Entre usuários autorizados dentro da mesma organização
  • Com provedores de infraestrutura e serviços essenciais (ex.: hospedagem, notificações), sempre sob contrato e confidencialidade
  • Quando exigido por lei ou ordem judicial

5. Armazenamento e segurança

Os dados são armazenados em ambientes seguros, com medidas técnicas e administrativas adequadas, incluindo:

  • Controle de acesso por perfil
  • Criptografia de dados sensíveis
  • Monitoramento de atividades
  • Logs de auditoria

O acesso às informações é restrito a usuários autorizados.

6. Retenção dos dados

Os dados são mantidos:

  • Enquanto o usuário estiver ativo na plataforma
  • Pelo período exigido por obrigações legais
  • Conforme definido pela empresa contratante

Após esse período, os dados podem ser anonimizados ou excluídos.

7. Direitos do usuário

Nos termos da Lei Geral de Proteção de Dados (LGPD), o usuário pode solicitar:

  • Confirmação da existência de tratamento
  • Acesso aos seus dados
  • Correção de dados incorretos
  • Exclusão ou anonimização, quando aplicável
  • Informações sobre compartilhamento

Solicitações devem ser feitas pelo e-mail: contato@analyzex.com.br

8. Dados de menores

A AnalyzeX é destinado a uso corporativo. Não é voltado a crianças ou adolescentes sem autorização da empresa responsável.

9. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada a qualquer momento. A versão mais recente estará sempre disponível no mesmo endereço.

10. Contato

Em caso de dúvidas sobre esta Política ou sobre o tratamento de dados:
